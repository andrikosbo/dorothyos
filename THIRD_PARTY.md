# Third-party software, artwork and trademarks

DorothyOS is an **integration** project: the repository contains scripts, QML, packaging files and original artwork. The
flashable images additionally contain a large amount of other people's software. This file says what, under which licences, and
what you may and may not do with the names. It is not legal advice.

## 1. What the repository itself contains

| Part | Licence | Notes |
|---|---|---|
| Scripts, QML, packaging (`build/`, `flash/`, `overlay/`, `tests/`, `docs/`) | MIT (`LICENSE`) | © Andreas Boglou and DorothyOS contributors |
| Wallpapers (`branding/wallpapers`, `/usr/share/wallpapers/DorothyOS-*`) | CC0 1.0 | generated by `make-wallpapers.py`, no third-party photo used |
| Logo, wordmark, app icon, boot splash (`branding/logo`, `branding/splash`) | CC BY 4.0 | the wordmark was traced from artwork supplied by the project |
| Home-screen tile icons (`overlay/dorothyos-tablet/src/hometiles`) | generated by `system/make-tile-icons.py` (plate, shadow, shape = original); the glyph inside each tile is the icon of the respective KDE / GNOME application | the licences of those icon sets (KDE Breeze: LGPL-3.0; GNOME app icons: see the apps' appdata); no third-party *brand* tile is shipped |

Nothing in the repository is copied from the postmarketOS, Nura, KDE or Alpine source trees except for API usage patterns (for example
the Plymouth script theme calls follow the stock `pmos-spin` theme; no file was copied).

## 2. What the images contain (not in this repository)

`pmbootstrap` assembles the image from the **postmarketOS binary repository** (an Alpine Linux edge derivative). Every package in an
image is listed with its version and SPDX licence in the file `dorothyos-<version>-<panel>.packages.txt` published next to the image
(generated from the image's own apk database). The main groups:

| Group | Licences | Where the source is |
|---|---|---|
| Linux kernel (`linux-xiaomi-pipa` 7.2.4: kernel.org tarball plus the patch series of the postmarketOS package) | GPL-2.0-only | <https://cdn.kernel.org/pub/linux/kernel/v7.x/>; patches and config: <https://gitlab.postmarketos.org/postmarketOS/pmaports/-/tree/master/device/testing/linux-xiaomi-pipa> |
| Alpine / postmarketOS base (musl, busybox, apk-tools, systemd, mkinitfs …) | MIT, GPL-2.0, … | <https://gitlab.alpinelinux.org/alpine/aports>, <https://gitlab.postmarketos.org/postmarketOS/pmaports> |
| KDE Plasma 6, KDE Frameworks, KDE apps (Dolphin, Kate, Okular, Gwenview, Konsole, Discover, Plasma Setup …) | GPL-2.0/3.0, LGPL, MIT, … | <https://invent.kde.org> |
| Qt 6 | LGPL-3.0 / GPL-3.0 | <https://code.qt.io> |
| Mesa (freedreno / turnip), libcamera, PipeWire, NetworkManager, BlueZ, … | MIT, LGPL, GPL | upstream projects |
| Firefox, VLC, GNOME Snapshot, Flatpak | MPL-2.0, GPL-2.0, GPL-3.0, LGPL | upstream projects |
| Device firmware: `linux-firmware-{qcom,qca,ath10k,ath11k}` | **proprietary binary blobs under redistribution licences** (Qualcomm, Qualcomm Atheros, Linaro, Dell) whose texts must accompany them | upstream linux-firmware via Alpine; texts in `docs/firmware-licenses/` and the release file `FIRMWARE-NOTICES.txt` |
| Device firmware: `firmware-xiaomi-pipa-*` (touch, GPU zap shader, DSPs, video, audio amplifier) | **proprietary, no licence statement found** (see `docs/FIRMWARE.md`) | postmarketOS package `firmware-xiaomi-pipa`, files from <https://github.com/pipa-mainline/xiaomi-pipa-firmware>; required for touch, GPU, audio, sensors, video |
| Fonts (`font-droid`, `font-twemoji`) | Apache-2.0, CC-BY-4.0 / MIT | upstream |

**Firmware:** what it is, the terms, the open point about the device-specific files and how to object: `docs/FIRMWARE.md`.

### GPL source offer
For every GPL/LGPL package in the image the corresponding source is available from the repositories above (the `*.packages.txt`
lists the exact package versions; the Alpine/postmarketOS source tarballs are mirrored at <https://dl-cdn.alpinelinux.org/alpine/edge/>
and <https://mirror.postmarketos.org/>). On request (open an issue) the maintainers will point you to the exact source of any
component of a published image for at least three years after the release.

### Not included on purpose
* **U-Boot** for the tablet (the bootloader package built by the postmarketOS / pipa-mainline community) is **not** redistributed:
  see `docs/BOOTLOADER.md` for where to get it.
* Android images, Xiaomi's stock ROM, Google apps, third-party Flatpaks and web-app tiles of other companies.
* The first-boot account, passwords, ssh keys and device-unique data (`docs/SECURITY-MODEL.md`).

### Downloaded on demand (never bundled)
* **Cosmic Camera** (`io.github.cosmic_utils.camera`, GPL-3.0) is offered by the *Camera* launcher the first time it is used; it is
  downloaded from Flathub by the user's own action (≈ 170 MB). The project does not redistribute it.
