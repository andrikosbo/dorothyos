# Firmware licence texts

Unmodified copies of the licence and notice files that the upstream **linux-firmware** project (tag `20261019`, directory `LICENSES/`,
<https://git.kernel.org/pub/scm/linux/kernel/git/firmware/linux-firmware.git>) names for the firmware in the packages
`linux-firmware-qcom`, `linux-firmware-qca`, `linux-firmware-ath10k` and `linux-firmware-ath11k` that are part of the DorothyOS images.
They are third-party texts, not covered by the MIT licence of this repository, and must stay together with the firmware they belong to.
What the files are, which conditions they set and how DorothyOS meets them: `../FIRMWARE.md`.

| File | Mentioned in upstream `WHENCE` for |
|---|---|
| `LICENSE.qcom`, `NOTICE.qcom`, `LICENSE.qcom-2` | Qualcomm firmware (remote processors, GPU, video, Wi-Fi, Bluetooth) |
| `LICENSE.QualcommAtheros_ath10k` | Qualcomm Atheros Wi-Fi / Bluetooth (`ath10k`, `ath11k`, `qca`) |
| `LICENSE.dell` | files supplied by Dell |
| `LICENCE.linaro` | files supplied by Linaro |
| `LICENSE.qcom_yamato` | two old Adreno microcode files |
